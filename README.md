# Proyecto-1-curso-analisis-de-datos.
Proyecto 1:  Sistema de Business Intelligence &amp; Analytics para Retail (Tableau &amp; Excel )

•	Diseñé un dashboard interactivo en Tableau (.twbx) incorporando funciones de agregación, filtros dinámicos, mapas y analítica avanzada, donde definí e integré métricas clave de negocio como Ingreso Total, Unidades Vendidas y la correlación de rendimiento por producto.

•	Automaticé la generación de un reporte ejecutivo en Excel mediante VBA y Macros, integrando segmentadores, tablas dinámicas y gráficos interactivos para usuarios no técnicos.

•	Impacto: Facilité la toma de decisiones gerenciales mediante la definición y análisis visual de KPIs estratégicos, incluyendo el comportamiento temporal de ingresos, la segmentación regional de ventas y el rendimiento por categorías de producto.
